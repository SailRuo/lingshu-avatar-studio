What it does

从设定到会说话的角色，都在一个窗口里。

不是把一堆模型 API 拼在一起，而是把“生成、分层、绑定、聊天、语音、导出”串成一条能反复使用的创作流程。

01 / 模型

你自己的模型

生图模型、多模态模型、语音模型都可以自带 Key；支持 OpenAI 兼容接口和常用国内服务商，模型列表自动获取。

02 / 智能体

一个模型，既看图也聊天

不再区分“视觉模型”和“对话模型”。同一个多模态模型负责分析立绘、规划图层，也负责舞台上的对话。

03 / 绑定

自动分层，自动绑骨

识别人脸、头发、眼睛和嘴，拆成图层，生成枢轴、视差和参数绑定。目标档位是完整分层，失败时自动降级。

04 / 声音

会眨眼，也会开口

待机呼吸、轻微摆动、随机眨眼；TTS 音频驱动口型。可以试听，也可以随时停下。

05 / 角色包

带走你的角色

导出 ZIP 角色包，换设备导入；也可以导出分层 PSD，继续在 Cubism Editor 里手工加工。

06 / 本地

默认本地优先

密钥在 macOS 安全存储，角色在本地数据库。没有云端账号，也没有悄悄上传。

Why desktop

网页能做展示，但做不了真正的创作工具。

浏览器会拦截商汤日日新这类接口的跨域预检。要绕过去，要么让用户自己起一个本地代理，要么让你替用户转发请求—— 前者难用，后者意味着你要承担带宽和用户的 Key。我们都不选。

桌面客户端直接用本机网络层请求模型，没有 CORS 这道墙；密钥只在本机，请求不经过任何服务器。 所以真正干活的版本是桌面端，网页只负责介绍和下载。

One honest note

它是自研 2.5D 角色包，不是 Live2D `.moc3`。

Live2D 的 `.moc3` 只能由 Cubism Editor 导出，网页和 AI 都没法一键生成。这里用的是我们自己的分层、网格和参数格式， 能在应用里转头、眨眼、说话；导出 PSD 后，你可以继续在 Cubism Editor 里手工绑定成真正的 Live2D 模型。
